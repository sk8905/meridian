# Style inventory — October 2026 (HOUSE_STYLE R43 pass)

The checklist for the R43 pass ("one professional list & table style, everywhere",
owner 2026-10-15). Every table and repeated-row list in the live v2 SPA, recorded
**before** the pass, with its column order, date format, row height / line count,
bold usage and text tiers. Generated by a headless DOM audit of each surface at
**1920×1080** and **iPhone 390×844** (dark), stubbed `/api/*` exactly as the specs run
(`tests/lib.mjs`), then annotated by hand. Live-only cards (prediction markets, X
wire, live tapes) render their empty/last-known state under the stubs.

**Legend.** *Kind* — **events** = a list/table of dated items (R43a); *data* = dated
market data or a roster (not an events list). *Order* — the table's header (or the
first → last text of a row). *Date* — the date format seen in the row. *Rows · height* —
rows rendered and the distinct row heights (more than one = uneven). *iPhone height ·
lines* — the same list at 390px; *lines* is row height ÷ line-height (padding
included, so a clean two-line row reads ≈2.5–3). *Status* — ☐ open · ☑ converted
(see "After" at the end).

## What the audit found (summary)

| Rule | Before the pass |
|---|---|
| R43b date first, source last | Dashboard `newsLi` rows lead with the headline, date bottom-left, tag bottom-right (R40's old format); Deals tables put Date 7th of 8 columns; LP commitments, stress table and Fundraising closes put the date near the end; hub stress / plans rows carry the date in the meta line; Profile wire rows already lead with the date. |
| R43b "15 Oct 26" | Five formats in use: "13 Oct 2026" (Dashboard, feed `fmtDay`, legal `fmtDate`), "01 Oct 2026" (credit `fmtDate`, zero-padded), "13 Oct" (digest, earnings, search, notifications, manager wire), "Oct 2026", "Oct '26" (chart axes — left as axis labels). |
| R43c two lines max | Dashboard news rows wrap to 3–4 lines (65px); funds-in-market rows 49–124px; Deals rows wrap the borrower (33/46px); briefing bullets 150–180px; the hub was the only list at one fixed height (50px). |
| R43d three tiers | `--t-dim` (a fourth grey) used by 50 declarations (Home rails, wire, Dashboard); legacy `--muted`/`--faint` greys on old Deals/Profiles CSS; coloured tags (stress red, priced green, filed purple, stale amber). |
| R43e bold only for headings | 438 bold declarations across 11 stylesheets, ~300 on body text: names (`.rxh-i-n`, `.crr-nm`, `.tmini-t`, `.mg-n`, `.dsh-nm`), figures (`.dsh-kv-v`, `.dsh-spread-v`, `.dsh-fl`, `.tinv-amt`), tags (`.dsh-tag`, `.tw-tag`, `.g-feed-code`), table heads (`.dsh-tbl th`, `.tleague th`, `.tx-mx th`), briefing `<strong>` highlights, deal-stat `<b>` figures. |
| R43f even columns | No shared table style: `.dsh-tbl` heads 500/body-size/mut, `.tleague` heads micro/uppercase/legacy `--muted`, `.tx-mx`, `.mac-mtx`, `.g-fx-tbl`, `.na-fx-tbl` each their own; the Deals list lets Borrower/Lender wrap while Source clips. |
